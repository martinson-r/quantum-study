## Experiments

- `hello_quantum.py` — first one-qubit circuit

```
q: ──H──M──
       │
c: ────╫──
       0
```

The pieces are:

q: = the quantum bit, or qubit

H = a Hadamard gate

M = measurement

c: = a normal classical bit where the measurement result gets stored

0 = measurement goes into classical bit 0
